## 규칙

- 트랙 하나 = 폴더 하나 = 독립된 환경. 파이썬 트랙이면 그 폴더 안에 자기만의 `pyproject.toml`과 `.venv`를 둬요.
- 모든 트랙 폴더는 같은 뼈대를 가져요.
  - `README.md`: 로드맵과 진행 현황
  - `lab-log.md`: 날짜별 학습 일지
  - `phases/NN-이름/`: 단계별 실습 폴더. 안에 `README.md`(할 일), `notes.md`(예측·결과·해석), 실습 코드, `results/`를 둬요.
- 새 트랙을 시작하면 위 표에 한 줄 추가해요.
- git으로 관리해요. 한 단계를 끝낼 때마다 커밋해 두면 나중에 비교하기 좋아요.
